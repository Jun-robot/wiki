教師あり学習
- データ
    - 特徴量とラベルを含むデータセット
        - 降雨を予想するなら
            - 特徴量 Feature : 軽度、気温、湿度、気圧
            - ラベル Label: 降水量
- データセット
    - サイズと多様性が大事
        - 100年分の7月のデータがあっても1月の降雨量は予想しにくい
        - サイズがデカくて、多様性が高いのがベスト
    - 特徴量が多いと良い
        - 湿度、気圧、気温の3つの特徴量よりも
        - 衛星画像や雲量まで含まれてた方がbetter
            - ラベルと因果関係がないと逆効果
- モデル
    - (教師あり学習では)
    - 入力特徴パターンから特定の出力ラベル値への数学的な関係を定義する数値の集合
    - トレーニングを通して、このパターンを検出する
- トレーニング
    - 損失(予想値と実際の値の差)を小さくするようにモデルがソリューションを更新していく
        - Prediction vs Actual
        - どの特徴をトレーニングに使うかを選択できる。
- 評価
    - トレーニング済みモデルを評価（学習の程度を判断する）
    - ラベル付きデータセットを使って、モデルの予想とラベルの真の値を比較する
        - Predicted Values vs Actual Values
